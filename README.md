# Nerdy Info Mod

Cookie Clicker quality-of-life tools that keep the vanilla game feeling like itself.

Features include:

- FtHoF planning
- Freebies: suggestions for easy achievements
- Optional Nerd cookie texture
- Optional scroll-wheel clicking

The convenience options are off by default. The mod does not automatically buy, cast, unlock, or change game progression.

For manual loading in Cookie Clicker, run:

```js
Game.LoadMod('https://raw.githubusercontent.com/lummasharp/nerdy-info-mod/main/main.js');
```
